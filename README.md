# 抗日战争 · 月度战局地图

一个无构建依赖的静态前端地图组件。内置 1937 年 7 月至 1945 年 9 月的 99 个月索引，使用本地 Leaflet 矢量组件和本地 GeoJSON 表达日军/伪政权、中国政府、敌后根据地与争夺区，并显示关键战役。应用不调用在线地图瓦片。

## 本地运行

在仓库目录执行：

```bash
python3 -m http.server 4173
```

然后打开 <http://localhost:4173/>。应用使用 ES module 数据文件，请通过 HTTP 服务打开，不要直接双击 `index.html`。

## GitHub Pages

仓库包含 `.github/workflows/pages.yml`。将代码推送到 `main` 后，在 GitHub 仓库的 **Settings → Pages** 中把发布来源设为 **GitHub Actions**；之后每次推送到 `main` 都会自动部署。项目型 Pages 地址通常是 `https://<用户>.github.io/<仓库名>/`，页面资源已经使用相对路径，能适配这个子路径。

地图边界、国家背景和战役点位均从仓库内 GeoJSON 加载；公网查看只需要静态文件托管，不依赖在线地图瓦片。

## 数据口径

地图是本地 Leaflet 渲染的真实地理矢量图，现代省界来自 `src/data/china-provinces.geojson`（仅定位参照），东亚背景来自 `src/data/east-asia-countries.geojson`；历史省级层从 `src/data/historical-provinces-1932-1944.geojson` 加载 1932—1944 民国省级示意轮廓，再以 `historicalProvinces.js` 标注 1937—1945 年的民国、满洲国和蒙疆省名。来源项目明确该轮廓用于历史定位、不是现代测绘，所以地图用虚线、弹窗和图例标明“历史示意边界”；台湾补充为日本殖民时期的现代几何定位代理。若要得到 1937 年逐县可审计边界，仍需按授权接入 CHGIS 时序数据。历史颜色层仍是研究性控制判断，不代表逐月精确行政边界或平方公里面积。控制态势按城市、港口、铁路、据点与根据地表达；月度控制区之间可能重叠。事件和口径参见仓库内的 [`report.md`](./report.md)。

历史几何署名和许可说明见 [`src/data/ATTRIBUTIONS.md`](./src/data/ATTRIBUTIONS.md)。

## 交互功能

- 1937 年 7 月至 1945 年 9 月的 99 个月滑块、下拉跳转、上一月／下一月和自动播放。
- Leaflet 地图提供本地 GeoJSON 矢量边界、1932—1944 历史省级分区层、月份控制着色、历史行政名称索引点、战役点位、五方势力节点／推进轴、图层开关、缩放和弹出详情。
- 地图工具栏的 ⛶ 可切换全屏地图视图，标题、图例和史料口径会叠加在地图边缘；再次点击或按 `Esc` 返回页面布局。
- 每月事件、控制区文字快照、阶段摘要和月度索引同步更新。

## 控制状态的证据等级

地图颜色表示“截至该月的控制判断”，不是现代行政区的主权归属。为避免把战时报纸上的“占领”误读为整省有效治理，数据层应同时保留 `status`、`confidence`、`source` 和 `scope` 字段：

- **直接占领（A）**：战报或战史明确记载攻占、撤退或持续驻军的城市、港口、铁路节点。多边形只表示该地理单元的示意范围，不外推到整个省。
- **名义行政（B）**：日伪政权设有行政机构，但治安和税粮依赖日军或伪军。采用低饱和色和虚线边界，并与直接占领分开。
- **国民政府稳定控制（A/B）**：能够持续组织行政、征税、征兵和驻军的后方或战区。省级色块仍须注明“省内局部可能为争夺区”。
- **敌后根据地（B）**：有八路军、新四军或地方抗日武装活动、政权建设的明确记载；用斜线纹理叠加，不把它和完整行政控制相加。
- **争夺／推定（C）**：只知道战线、据点或交通线在该月附近变化，无法确定县内控制的，使用半透明和交叉纹理。阶段之间的插值必须标为“推定”。

公开史料不存在一套可以直接逐月复核的县级控制边界。本项目新增的 `src/data/historicalAdmin.js` 深入到特别市、市／省治、县级驻地和镇级战场点，保留北平、石门、归绥、新京、延安县、台儿庄镇等历史名称，并在弹窗中显示现代定位、当时所属和来源。它是历史行政名称／驻地索引，不是县界复原。历史省级层使用 1932—1944 示意轮廓，弹窗公开来源和几何状态；若要绘制可审计的 1937 省县多边形，下一步应按授权接入 CHGIS 时序数据并逐幅对照民国行政区划和战史地图。
